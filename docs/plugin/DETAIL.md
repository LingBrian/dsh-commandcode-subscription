Add and switch API keys in the Command Code accounts page in DSH settings, or keep using `COMMANDCODE_API_KEY` from the credential service. Select a `commandcode-go` model to chat. The accounts page refreshes each account's 5-hour, weekly, and monthly quotas every 30 seconds. The plugin uses Command Code's experimental `/alpha/generate` API and does not support OAuth. Entitlement and billing depend on the provider.
