Configure `COMMANDCODE_API_KEY` through the DSH credential service, then select a `commandcode-go` model. The plugin uses Command Code's experimental `/alpha/generate` API and does not support OAuth. View 5-hour, weekly, and monthly quotas in plugin settings. Entitlement and billing depend on the provider.
