在 DSH 设置的 Command Code 账户页面添加、切换多个 API Key，或继续使用凭证服务中的 `COMMANDCODE_API_KEY`。选择 `commandcode-go` 模型后即可对话。账户页面每 30 秒刷新各账户的 5 小时、每周、每月额度。插件使用实验性的 Command Code `/alpha/generate` 接口；不支持 OAuth。实际权限和费用以服务商为准。
