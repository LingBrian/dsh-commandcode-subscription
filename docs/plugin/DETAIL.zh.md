通过 DSH 凭证服务配置 `COMMANDCODE_API_KEY`，再选择 `commandcode-go` 模型。插件使用实验性的 Command Code `/alpha/generate` 接口；不支持 OAuth。可在插件设置中查看 5 小时、每周和每月额度；实际权限和费用以服务商为准。
